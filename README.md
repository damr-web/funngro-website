# Funngro Website Revamp

A responsive two-page concept redesign created for the Funngro Website Revamp project.

## Pages
- `index.html` — For Teens landing page
- `company.html` — Company / About page
- `style.css` — Shared responsive styling

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for GitHub Pages to publish the site.

This is an independent concept redesign and is not the official Funngro website.
